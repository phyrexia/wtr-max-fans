# wtr-max-fans

Fan control for the AOOSTAR WTR MAX NAS (ITE IT8613E): a patched `it87` driver installed with DKMS, disk-temperature-driven fan curves, a quiet night mode and an independent disk-overheat guard, configured from a simple terminal menu.

**Status: in design. Not ready for use.**

Not affiliated with or endorsed by AOOSTAR.
